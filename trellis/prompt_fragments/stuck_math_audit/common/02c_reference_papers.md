## Additional reference papers

The operator has registered additional reference papers as grounding authority for results the primary paper cites. The registry is in the structured request under `reference_papers` (id -> `{tex_path, source_id}`, paths relative to the repo root), with live node claims under `node_reference_grounds`. When a node under audit claims one of these documents, read the claimed file to judge how the node grounds the cited result. The primary paper remains the sole target authority.
