### 3. Route a physically unrealizable witness

When the disproof holds and the Rust language admits `x0`, but realizing it
would require hardware the eligibility rubric calls exotic or possibly
nonexisting, rule `under_model_ruling: "bug"`, leave `set_live_polarity`
empty, and file the `conditional_theorem_proposal` the proposal section
describes, with a condition that excludes the witness class and the hardware
property that class demands in `rationale`.
