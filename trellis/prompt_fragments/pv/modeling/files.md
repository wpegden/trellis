`python3 .trellis/scripts/pv_modeling.py check` accepts --through cargo|charon|aeneas|lean and --fresh. Its other subcommands take the same run root: inspect <root> gives a bounded summary of the supervisor observation; --observation <path> selects a check result. --symbol <name>, --module, and --source focus on declarations and their diagnostics. Add --ir to a symbol query for Charon's readable intermediate code and header locations. Results link to the full index, and declaration references are navigation hints. probe <root> --source <crate-tree> checks a scratch crate in the extraction environment. exec <root> --cwd <directory> --command <argv...> runs a diagnostic with the configured tools, forwarding the complete command unchanged. compare <root> --baseline <source-tree> --candidate <source-tree> --command <argv...> compares exact stdout from successful commands run in each side’s scratch directory, substituting {source} with its source copy and {scratch} with that directory. Use scratch copies for commands that write into a source tree. Full output and execution results remain in scratch. Command tools accept --timeout <seconds> with no upper cap. A timeout is an incomplete observation; retry with more time before adapting source solely for elapsed time.

Source commands in agent shells use the configured Rust toolchain and run-local build storage. Create a distinct directory under .trellis/scratch for each experiment. Supervisor observations and cache entries are read-only to agents.

Full Lean checks also retain `axiom_dependencies`: elaborated declaration inventories, with unresolved declarations and their dependents marked pending. The export report compares confirmed dependencies with the existing axiom policy and links every unapproved axiom to affected declarations. Compilation alone does not establish axiom compatibility; imports and default proof arguments can introduce dependencies absent from the raw source inventory.
