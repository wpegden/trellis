## Cleanup

Cleanup begins with a fully formalized development and performs bounded improvements to its presentation and structure. The accepted model, goal meanings, and proved results remain fixed.

An audit proposes cleanup tasks, and the reviewer selects useful work for workers to perform. Tasks can remove redundant wrappers through checked substitutions or resolve build warnings. Each task has a defined edit scope, and accepted changes preserve the formalization completion conditions.

Cleanup ends when every task is completed, failed, or dismissed; the reviewer chooses to finish; or three consecutive worker failures trigger the automatic stop. Failed changes preserve the previous accepted development. The final artifact includes the successfully accepted cleanup changes.
