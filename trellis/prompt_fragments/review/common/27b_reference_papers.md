## Additional reference papers

The operator has registered additional reference papers grounding results the primary paper cites. The registry is in `request_summary.reference_papers` (id -> `{tex_path, source_id}`, paths relative to the repo root); live node claims are in `request_summary.node_reference_grounds`. The primary paper remains the sole target authority.

A `paper_focus_ranges` entry may carry `doc: "<id>"` to cite lines from a registered reference paper; an entry without `doc` cites the primary paper.
